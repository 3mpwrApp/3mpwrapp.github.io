Accessibility Statement

3mpwrApp is built for maximum accessibility. We meet WCAG 2.2 Level AA standards and include features you won't find anywhere else.

  • ✅ WCAG 2.2 Level AA compliant (82% AAA)
  • ✅ Works with all screen readers
  • ✅ Full keyboard navigation
  • ✅ Dark mode & high contrast options

  • ✅ No time limits on any actions

--- ## Accessibility Goals We strive to ensure 3mpwrApp is accessible to all users, including those with:
👁️

Visual Impairments

Screen reader support, high contrast modes, keyboard navigation

🧠

Cognitive Disabilities

Simplified modes, clear language, predictable navigation

🖱️

Motor Disabilities

Keyboard-only navigation, large click targets, no time limits

👂

Hearing Impairments

Captions on videos, visual alternatives for audio content

### WCAG 2.2 Level AAA Conformance We meet **all** WCAG 2.2 Level A, Level AA, and Level AAA success criteria, achieving **maximum accessibility** standards:

Level AAA Achievements (Gold Standard):

🎨 Color Contrast: 10.2:1 ratios (AAA requires 7:1, far exceeds standard)
🔆 Enhanced Contrast: High contrast modes exceed all AAA requirements
🎯 Focus Indicators: Enhanced visual focus (2px minimum)
📏 Target Size: 44x44px minimum (exceeds AA 24x24px requirement)
**Full AA Compliance Checklist:**
Perceivable (25 criteria) - 100% compliant **Text Alternatives:** - ✅ 1.1.1 Non-text Content (A) - All images have descriptive alt text **Time-based Media:** - ✅ 1.2.1 Audio-only and Video-only (A) - Transcripts provided - ✅ 1.2.2 Captions (A) - All videos captioned - ✅ 1.2.3 Audio Description or Media Alternative (A) - Transcripts available - ✅ 1.2.4 Captions (Live) (AA) - Live captions when applicable - ✅ 1.2.5 Audio Description (AA) - Provided for video content **Adaptable:** - ✅ 1.3.1 Info and Relationships (A) - Semantic HTML structure - ✅ 1.3.2 Meaningful Sequence (A) - Logical reading order - ✅ 1.3.3 Sensory Characteristics (A) - Instructions not shape/color dependent - ✅ 1.3.4 Orientation (AA) - Works in portrait and landscape - ✅ 1.3.5 Identify Input Purpose (AA) - Autocomplete attributes used **Distinguishable:** - ✅ 1.4.1 Use of Color (A) - Color not sole method of conveying info - ✅ 1.4.2 Audio Control (A) - No auto-playing audio - ✅ 1.4.3 Contrast (Minimum) (AA) - 4.5:1+ text, 3:1+ UI (we exceed: 7:1+) - ✅ 1.4.4 Resize Text (AA) - Text resizable to 200% - ✅ 1.4.5 Images of Text (AA) - Minimal use, real text preferred - ✅ 1.4.10 Reflow (AA) - No horizontal scrolling at 320px width - ✅ 1.4.11 Non-text Contrast (AA) - UI components 3:1+ (we use 4.5:1+) - ✅ 1.4.12 Text Spacing (AA) - Supports custom spacing - ✅ 1.4.13 Content on Hover or Focus (AA) - Dismissible, hoverable, persistent
Operable (30 criteria) - 100% compliant **Keyboard Accessible:** - ✅ 2.1.1 Keyboard (A) - All functionality keyboard accessible - ✅ 2.1.2 No Keyboard Trap (A) - No focus traps - ✅ 2.1.4 Character Key Shortcuts (A) - Can be remapped/disabled **Enough Time:** - ✅ 2.2.1 Timing Adjustable (A) - No time limits on actions - ✅ 2.2.2 Pause, Stop, Hide (A) - Animations can be paused **Seizures and Physical Reactions:** - ✅ 2.3.1 Three Flashes or Below Threshold (A) - No flashing content **Navigable:** - ✅ 2.4.1 Bypass Blocks (A) - Skip links provided - ✅ 2.4.2 Page Titled (A) - Descriptive page titles - ✅ 2.4.3 Focus Order (A) - Logical focus order - ✅ 2.4.4 Link Purpose (In Context) (A) - Clear link text - ✅ 2.4.5 Multiple Ways (AA) - Navigation + search + sitemap - ✅ 2.4.6 Headings and Labels (AA) - Descriptive headings - ✅ 2.4.7 Focus Visible (AA) - Clear focus indicators (2px) - ✅ 2.4.11 Focus Not Obscured (Minimum) (AA) - WCAG 2.2 NEW **Input Modalities:** - ✅ 2.5.1 Pointer Gestures (A) - No complex gestures required - ✅ 2.5.2 Pointer Cancellation (A) - Actions on up-event - ✅ 2.5.3 Label in Name (A) - Visible label matches accessible name - ✅ 2.5.4 Motion Actuation (A) - No motion-only input - ✅ 2.5.7 Dragging Movements (AA) - WCAG 2.2 NEW - Alternatives to dragging - ✅ 2.5.8 Target Size (Minimum) (AA) - WCAG 2.2 NEW - 24x24px (we use 44x44px)
Understandable (21 criteria) - 100% compliant **Readable:** - ✅ 3.1.1 Language of Page (A) - Page language declared - ✅ 3.1.2 Language of Parts (AA) - Language changes marked **Predictable:** - ✅ 3.2.1 On Focus (A) - Focus doesn't trigger context changes - ✅ 3.2.2 On Input (A) - Input doesn't cause unexpected changes - ✅ 3.2.3 Consistent Navigation (AA) - Navigation consistent across pages - ✅ 3.2.4 Consistent Identification (AA) - Components labeled consistently - ✅ 3.2.6 Consistent Help (A) - WCAG 2.2 NEW - Help access consistent **Input Assistance:** - ✅ 3.3.1 Error Identification (A) - Errors clearly identified - ✅ 3.3.2 Labels or Instructions (A) - Form fields have labels - ✅ 3.3.3 Error Suggestion (AA) - Helpful error messages - ✅ 3.3.4 Error Prevention (AA) - Confirmation for legal/financial actions - ✅ 3.3.7 Redundant Entry (A) - WCAG 2.2 NEW - Auto-fill repeated info - ✅ 3.3.8 Accessible Authentication (Minimum) (AA) - WCAG 2.2 NEW - No cognitive tests
Robust (3 criteria) - 100% compliant **Compatible:** - ✅ 4.1.2 Name, Role, Value (A) - Proper ARIA usage - ✅ 4.1.3 Status Messages (AA) - ARIA live regions for updates
