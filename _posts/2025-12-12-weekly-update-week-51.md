**December 9, 2025 — Our first demo and introduction presentation was a success!**

- **USA listeners expressed interest in beta testing!**

## 🇺🇸 USA Lite Launched!

In response to interest from American supporters during the demo, we've launched **USA Lite**!

### What is USA Lite?
A version of 3mpwrApp for US-based users who want to:
- Join beta testing and provide feedback
- Use core wellness and advocacy features
- Experience disability-first design
- Help shape future US-specific features

### Feature Availability

| Feature Category | USA Lite Status |
|-----------------|-----------------|
| **Wellness Hub** | ✅ Full Access |
| **Evidence Locker** | ✅ Full Access |
| **Energy Management** | ✅ Full Access |
| **Community Features** | ✅ Full Access |
| **Privacy & Security** | ✅ Full Access |
| **Offline-First** | ✅ Full Access |
| **Letter Templates** | 📝 Generic Templates |
| **Benefits Navigator** | 🔄 US Adaptation Planned |
| **Indigenous Languages** | ❌ Canada Only |

### Why the Difference?
3mpwrApp was built for Canadian disability benefits (ODSP, CPP-D, AISH, etc.). USA Lite offers universal features while we work on US-specific adaptations.
