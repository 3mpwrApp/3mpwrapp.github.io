# Legal & Business Documentation

This directory contains all legal, governance, business, and compliance documentation for 3MPWR.

## 📁 Structure

### `/governance/` - Organizational Governance
- `GOVERNANCE_SUCCESSION_PLAN.md` - Founder succession and community governance transition plan
- `IP_ASSIGNMENT_AGREEMENT.md` - Intellectual property assignment agreements  
- `MISSION_STATEMENT.md` - Official mission and values statement

### `/policies/` - Privacy & Data Policies
- `COLLECTIVE_EVIDENCE_PRIVACY_POLICY.md` - Privacy policy for Collective Evidence feature
- `DATA_GOVERNANCE.md` - Data ownership, handling, and governance framework
- `/release-prep/legal/` - App store legal requirements:
  - `privacy-policy.md` - Main privacy policy
  - `terms-of-service.md` - Terms of service
  - `DATA_OWNERSHIP_STATEMENT.md` - User data ownership guarantees
  - `community-guidelines.md` - Community behavior standards
  - `disclaimer-coverage-audit.md` - Legal disclaimers audit
  - `all-disclaimers-summary.md` - Comprehensive disclaimers overview

### `/compliance/` - Security & Compliance
- `SECURITY.md` - Security architecture and best practices
- `SECURITY_ARCHITECTURE.md` - Detailed security design
- `SECURITY_FRAMEWORK.md` - Security policies and procedures  
- `GITHUB_SECURITY.md` - GitHub-specific security policies

## 🏢 Business Documentation

### `/business/financials/` - Financial Planning

### `/business/infrastructure/` - Admin & Operations
