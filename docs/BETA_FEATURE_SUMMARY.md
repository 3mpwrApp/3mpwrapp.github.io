## 🐛 How to Report Issues

### In-App
Settings → About → Feedback

### Email
support@3mpwrapp.com

### What to Include
1. **What happened** - Describe the issue
2. **Expected behavior** - What should happen
3. **Steps to reproduce** - How to recreate it
4. **Device info** - iPhone 12, Android Pixel, etc.
5. **Screenshots** - If possible

## 💡 Beta Testing Tips

### Do:
✅ Use the app daily for realistic testing
✅ Try features outside your immediate needs
✅ Test accessibility features even if you don't need them
✅ Report even small bugs or odd behavior
✅ Suggest improvements and new features
✅ Share positive feedback too!

### Don't:
❌ Enter real sensitive data (beta environment)
❌ Share your test account with others
❌ Spam test data in community features
❌ Expect coming soon features to work
❌ Use for actual legal submissions yet
❌ Skip the feedback survey
