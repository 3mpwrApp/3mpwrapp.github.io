### Video Production Tips

1. **Accessibility First:**
   - Always include captions (auto-generated + manually reviewed)
   - Describe all on-screen visuals
   - Use clear, simple language
   - Avoid flashing/strobe effects

2. **Screen Recording Quality:**
   - Record at 1080p minimum
   - Use clear, readable font
   - Slow down gestures (zoom in)
   - Highlight important buttons/text

3. **Voice & Pacing:**
   - Speak slowly (20% slower than natural)
   - Pause frequently for comprehension
   - Use varied tone to maintain interest
   - Avoid jargon (or explain when needed)

4. **Thumbnail Design:**
   - Large, readable text
   - Contrasting colors
   - Show emotion/reaction if possible
   - Include disability representation

5. **SEO Optimization:**
   - Include keywords in title, description, tags
   - Use timestamps for every major section
   - Link to related videos
   - Add to relevant playlists
