# Closed Beta – Tester Guide (Free Path)

Welcome! This guide shows how to try the app in a private beta using Expo Go (free) and how to share feedback.

## How to join (iOS and Android)

1) Install Expo Go
- iOS: App Store → search “Expo Go” (by Expo). Free.
- Android: Play Store → search “Expo Go”. Free.

2) Open the private link
- We’ll send you a QR code or link (unlisted project). Open it in Expo Go.
- If prompted, create a free Expo account and sign in.

3) Sign in or use Guest
- The app supports Guest Mode. You can explore without an account.

4) Updates
- We’ll push updates to the beta link. Just reopen the project in Expo Go to receive the latest version.

## Known limitations in Expo Go

- Push notifications: Remote push is not available in Expo Go on Android; iOS requires special setup. We’ll use in‑app notices and local reminders during closed beta.
- Some native modules require a custom build; we’ve kept the beta within Expo Go’s supported APIs.

## What to test

- Wellness tools: Try daily planners, reflections, and exercises.
- Resources: Deadlines, rights info, evidence flows.
- Advocacy tools: Simple policy views, AI summaries (with clear disclaimers). Offline fallbacks always work.
- Accessibility & translations: Large fonts, screen readers, Spanish/French labels.

## How to report feedback

- Email: empowrapp08162025@gmail.com (attach screenshots if helpful)
- Or open a GitHub Issue (if invited): include steps to reproduce and your phone model/OS.
- Include the app version shown in Settings → About (or the date/time you opened the beta link).

## Privacy & safety

- Don’t share personal or confidential data in screenshots or issues.
- All AI outputs are educational, not legal advice.
- You can clear local data any time from Settings → Privacy.
