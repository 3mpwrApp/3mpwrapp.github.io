# Documentation

This folder contains development documentation, session summaries, and implementation guides for the 3mpwr App project.

## Contents

- **Architecture & Setup**: Firebase, authentication, cloud functions, and infrastructure guides
- **Feature Documentation**: Implementation summaries for campaigns, events, community, and wellness features
- **Session Summaries**: Daily development progress reports
- **Testing Guides**: Testing procedures and verification reports
- **Accessibility**: WCAG 2.2 AAA compliance audits and accessibility achievements
- **Deployment**: Launch checklists, deployment guides, and release procedures

## For Users

User-facing documentation is in the main [README.md](../README.md) and [CHANGELOG.md](../CHANGELOG.md) files.

## Contributing

When adding new documentation:
- Use clear, descriptive filenames
- Follow the existing naming conventions (UPPERCASE_WITH_UNDERSCORES.md for technical docs)
- Include date stamps for session summaries and time-sensitive documents
- Keep this README updated with major documentation categories
