## 📝 Documentation Guidelines

When adding new documentation:
1. ✅ Check if content fits in an existing document first
2. ✅ Use clear filenames (UPPERCASE_WITH_UNDERSCORES.md)
3. ✅ Update this README when adding major documents
4. ✅ Move completed work to archive/ when done
5. ✅ Keep the docs folder lean (~20 active files max)
