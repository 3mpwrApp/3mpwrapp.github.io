## 📱 Getting Started

### iOS (TestFlight)

1. **Install TestFlight** (if you don't have it):
   - Open App Store on your iPhone/iPad
   - Search for "TestFlight"
   - Install the official Apple TestFlight app

2. **Accept Beta Invitation**:
   - Check your email for the TestFlight invitation from 3mpwr
   - Tap "View in TestFlight" or use the invitation code
   - Tap "Accept" and then "Install"

3. **Install 3mpwr Beta**:
   - Open TestFlight app
   - Find "3mpwr" in your apps list
   - Tap "Install" or "Update" for new versions
   - Tap the app icon to launch

4. **Enable Auto-Updates** (Recommended):
   - In TestFlight, tap on 3mpwr
   - Enable "Automatic Updates"
   - You'll get new beta builds automatically

### Android (Google Play Beta)

1. **Join Beta Program**:
   - Open the beta invitation link sent to your email
   - Sign in with your Google Account
   - Tap "Become a tester"
   - Wait ~5 minutes for access to be granted

2. **Install 3mpwr Beta**:
   - Open Google Play Store
   - Search for "3mpwr" or use the direct link
   - You'll see "You're a beta tester" banner
   - Tap "Install" or "Update"

3. **Enable Auto-Updates** (Recommended):
   - In Play Store, go to 3mpwr app page
   - Tap ⋮ (three dots) menu
   - Enable "Auto-update"

4. **Leave Beta** (if needed):
   - Return to beta invitation link
   - Tap "Leave the program"
   - Uninstall and reinstall to get production version

## 🧪 What to Test

### Priority 1: Core Functionality
- [ ] **Onboarding Flow**: Complete the 7-day onboarding journey
- [ ] **Profile Setup**: Configure your disability profile, energy levels, and preferences
- [ ] **Navigation**: Test all 8 main tabs (Home, Campaigns, Community, Resources, Wellness, Advocacy, Settings, What's New)
- [ ] **Accessibility**: Enable your accessibility features (screen reader, high contrast, larger text, etc.)
- [ ] **Language**: Switch between English, French, and Spanish in Settings

### Priority 2: Key Features
- [ ] **Letter Wizard**: Create an advocacy letter using templates
- [ ] **Evidence Locker**: Upload a document (test with screenshot or PDF)
- [ ] **Wellness Tools**: Try mood tracker, sleep tracker, or energy coins
- [ ] **Community**: Browse channels, read posts (Beta)
- [ ] **Campaigns**: Join a campaign and track progress
- [ ] **Deadlines**: Add a deadline and set reminders
- [ ] **Notifications**: Test push notifications (enable in Settings first)
- [ ] **Bookmarks**: Save and unsave items across tabs

### Priority 3: Advanced Features
- [ ] **Cognitive Accessibility**: Enable step-by-step mode, breadcrumbs, navigation memory
- [ ] **Dyslexia Support**: Try dyslexia-friendly fonts and visual aids
- [ ] **Motor Accessibility**: Test dwell click, touch targets, tremor support
- [ ] **Voice Navigation**: Test voice commands (if available)
- [ ] **Offline Mode**: Turn off WiFi/data and test app functionality
- [ ] **Admin Tools**: (Admin testers only) Test analytics dashboard, user management

### Priority 4: Edge Cases
- [ ] **Low Battery**: Use app when battery is <20%
- [ ] **Low Memory**: Use app with many other apps running
- [ ] **Slow Network**: Test on 3G/slow WiFi
- [ ] **Rotation**: Rotate device (portrait ↔ landscape)
- [ ] **Background/Foreground**: Switch apps and return to 3mpwr
- [ ] **Interruptions**: Test incoming calls, notifications while using app

## 🐛 How to Report Bugs

### Where to Report
Choose **one** method:
1. **In-App Feedback** (Recommended):
   - Go to Settings → About & Feedback → "Send Feedback"
   - Auto-includes device info and app version
   
2. **Beta Testers Chat** (Best for quick issues):
   - Community → Beta Testers Chat
   - Post a message with your issue
   - Other testers may have solutions
   
3. **Email**: empowrapp08162025@gmail.com
   - Subject: [BETA] Short bug description
   - Include details below

### What to Include

**Required Information:**
- [ ] Device: (e.g., iPhone 14 Pro, Samsung Galaxy S24)
- [ ] OS Version: (e.g., iOS 17.5, Android 14)
- [ ] App Version: (Found in Settings → About & Feedback → Version)
- [ ] Bug Title: Short, specific description
- [ ] Steps to Reproduce:
  1. Go to...
  2. Tap on...
  3. See error...
- [ ] Expected Behavior: What should happen?
- [ ] Actual Behavior: What actually happened?
- [ ] Frequency: Always, Sometimes, Once?

**Optional but Helpful:**
- [ ] Screenshots: Show the issue
- [ ] Screen Recording: Record the bug happening
- [ ] Error Message: Exact text of any error
- [ ] Network Status: WiFi, Cellular, or Offline?
- [ ] Accessibility Settings: Which ones are enabled?
- [ ] Workaround: Did you find a way around it?

### Bug Severity Guide

**🔴 Critical (Report Immediately)**
- App crashes on launch
- Cannot create account / sign in
- Data loss (evidence, letters, etc.)
- Security vulnerabilities
- Privacy breaches

**🟠 High (Report Within 24 Hours)**
- Feature completely broken
- Cannot complete onboarding
- Evidence Locker not uploading
- Notifications not working
- Text unreadable (contrast issues)

**🟡 Medium (Report Within 3 Days)**
- Feature partially works
- UI element misaligned
- Translation errors
- Slow performance
- Minor accessibility issues

**🟢 Low (Report When Convenient)**
- Typos
- Cosmetic issues
- Feature suggestions
- Nice-to-have improvements

## 📝 Frequently Asked Questions

### General

**Q: How long is the beta period?**
A: Beta testing runs until we're confident the app is stable and feature-complete. Estimated: 2-4 weeks.

**Q: Will my data transfer to the production app?**
A: Yes, if you sign in with an account. Guest data may not transfer.

**Q: Can I use the beta app as my main app?**
A: Yes, but be aware bugs and data loss may occur. Back up important documents externally.

**Q: How often will I get updates?**
A: We aim for 1-2 updates per week during active beta testing.

**Q: What happens after beta ends?**
A: Your beta app will update to the production version automatically.

### Technical

**Q: The app crashed. What do I do?**
A: Restart the app and report the bug. Include what you were doing when it crashed.

**Q: I found a security issue. Who do I tell?**
A: Email empowrapp08162025@gmail.com immediately. Do NOT post publicly.

**Q: Can I test on multiple devices?**
A: Yes! Testing on different devices helps us a lot.

**Q: The app is slow. Is that normal?**
A: Some slowness is expected in beta. Report if it's unusable.

**Q: I want to leave the beta. How?**
A: iOS: Delete the app from TestFlight. Android: Leave beta program in Play Store.

### Privacy & Safety

**Q: Is my data safe in beta?**
A: Yes. We use the same encryption and security as production. But back up important documents externally.

**Q: Can other testers see my data?**
A: No. Your profile, evidence, and letters are private unless you share them.

**Q: What data do you collect?**
A: See Privacy Policy in Settings → Privacy. We collect minimal data for debugging (crash logs, anonymous usage).

**Q: Can I opt out of analytics?**
A: Yes. Settings → Privacy → Disable "Anonymous Usage Data" and "Crash Reporting".

## ⚡ Quick Testing Guide

**For busy testers: Complete this 5-minute test to catch the most common issues.**

### Step 1: Install & Launch (1 min)
1. Install the app via TestFlight (iOS) or Play Beta (Android)
2. Open the app and let it warm up for ~1 minute (caches loading)
3. Complete Terms & Conditions acceptance

### Step 2: Navigation Test (2 min)
1. **Tap every tab** in the bottom navigation:
   - Home, Campaigns, Community, Resources, Wellness, Advocacy, Settings, What's New
2. **Check for**:
   - No dead links or crashes
   - No error messages  
   - Loading states appear for lists
   - Back button works intuitively
3. **Try airplane mode**: Toggle airplane mode ON, verify app shows offline banner and cached content works

### Step 3: Key Feature Test (2 min)
Pick ONE feature to test thoroughly:
- **Letter Wizard**: Resources → Letter Wizard → Start a letter
- **Evidence Locker**: Advocacy → Evidence Locker → Upload test file
- **Mood Tracker**: Wellness → Mood Tracker → Log a mood
- **Community**: Community → Browse channels → Read a post

### Step 4: Report Issues
- **Settings → About & Feedback → Send Feedback**
- Or email: empowrapp08162025@gmail.com with subject "Beta: [feature name]"
- Include: What you tapped, what happened, what you expected

### Known Issues (Skip Testing These)
- iOS remote push notifications disabled (pending APNs setup)
- Some features labeled "Coming Soon"
- First launch may feel slow (caches warming up)
