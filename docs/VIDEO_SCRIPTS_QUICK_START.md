## 🎬 PRODUCTION CHECKLIST

### Before Recording Each Video
- [ ] Read full script
- [ ] Create storyboard (key 5-10 scenes)
- [ ] Plan screen recording path (click-by-click)
- [ ] Gather example data or screenshots
- [ ] Identify accessibility needs

### During Recording
- [ ] Record at 1080p minimum
- [ ] Use clear, readable font (18pt+)
- [ ] Slow down on-screen gestures
- [ ] Highlight important buttons with circles
- [ ] Quiet environment
- [ ] Good lighting

### After Recording
- [ ] Auto-generate captions (YouTube)
- [ ] Manually review captions (fix errors)
- [ ] Add timestamps for major sections
- [ ] Write description with all links
- [ ] Add 10-15 relevant hashtags
- [ ] Create custom thumbnail
- [ ] Schedule upload time

### Before Publishing
- [ ] Screen reader test (if applicable)
- [ ] Check no flashing/strobe effects
- [ ] Verify all links work
- [ ] Test on mobile (how do captions look?)
- [ ] Final quality check

## ❓ FAQ

**Q: Do I need experience to produce these videos?**
A: No! Scripts are detailed with every step. Just need basic screen recording + voiceover.

**Q: How long does each video take to produce?**
A: ~4-5x video length. So 10-min video = ~50 mins production (recording + editing + captions).

**Q: Can I batch record?**
A: YES! Record 4-6 videos in one session. Much more efficient.

**Q: Will these scripts guarantee viral videos?**
A: Scripts are high-quality, but virality depends on timing, promotion, community, and luck. Focus on consistent uploads + quality + engagement.

**Q: Do I need to follow the scripts exactly?**
A: No! These are frameworks. Add your personality, examples, experiences. Scripts are guides, not rigidity.

**Q: Which video should I produce first?**
A: Video 1 (Installation) or Video 5 (Home Tab). Both are evergreen and introduction-style.
