##  Method 2: Microsoft Edge (Recommended for Best Formatting)

1. Open file in Microsoft Edge
2. Press `Ctrl+P`
3. Under "Printer", select "Microsoft Print to PDF"
4. **IMPORTANT:** Click "More settings"
   - Paper size: Letter (8.5 x 11 in)
   - Margins: Default
   - Headers and footers: OFF (uncheck)
   - Background graphics: ON (check)
5. Click "Save"

**Result**: Cleanest PDF with proper colors and layout

## 🚨 Troubleshooting

**Problem**: Colors don't print
**Solution**: In print dialog, enable "Background graphics"

**Problem**: Page breaks look weird
**Solution**: Use Microsoft Edge instead of Chrome/Firefox

**Problem**: Text is too small

**Solution**: Open `TBDIWSG_PILOT_PROPOSAL_PDF.html` in a text editor, make changes, save, then print to PDF
