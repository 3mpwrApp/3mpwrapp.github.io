# Performance dashboard

This page summarizes performance artifacts generated by CI.

- Analytics report: `docs/analytics-report.md` (auto-updated during tests)
- Bundle budget: from `scripts/perf-bundle-budget.mjs`
- Bundle breakdown: from `scripts/perf-bundle-breakdown.mjs`
- Max file size guard: `scripts/perf-max-file-size.mjs`

Local runs (optional):

- npm run perf:budget
- npm run perf:breakdown
- npm run perf:max-file

Env knobs:

- PERF_BUDGET_SOFT / PERF_BUDGET_HARD
- PERF_MAX_FILE_BYTES (default 35000)
- PERF_MAX_ALLOW (comma-separated regex fragments)
