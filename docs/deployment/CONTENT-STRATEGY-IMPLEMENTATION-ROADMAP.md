### 🔟 PERSONALIZATION & RECOMMENDATION ENGINE
**File Created:** `scripts/personalization-engine.js`  
**What it does:** Smart recommendations that feel like "This content is made for me"

**Segmentation model (5 audience types):**
1. **Injured workers** → WSIB, workplace accommodation, return-to-work
2. **Benefits seekers** → CPP-D, ODSP, DTC, benefit maximization
3. **Accessibility advocates** → AODA, WCAG, barrier removal
4. **Newly disabled** → Foundational guides, first steps, community connection
5. **Caregivers** → Caregiver support, tax credits, burnout prevention

**Recommendation algorithm (weighted factors):**
- Content match (40%) - Does this align with reader's interests?
- Reading level (20%) - Is it right difficulty for their knowledge?
- Temporal relevance (15%) - Does this matter right now?
- Community signals (15%) - Are similar readers finding this valuable?
- Discovery factor (10%) - Show some serendipitous content

**Placements:**
- Blog post sidebar ("What to read next" - 3 articles)
- Email footer (personalized by segment)
- Homepage (if logged in)
- Search results (related topics)
- Thank-you pages (keep reader engaged)

**Implementation roadmap:**
- Phase 1 (Feb): Tag articles, basic related-content sidebar
- Phase 2 (Mar): User segmentation, algorithm testing
- Phase 3 (Apr-May): Homepage + email personalization
- Phase 4 (Jun+): Optimization & A/B testing

**Impact metrics:**
- Click-through rate on recommendations: 15-25% (vs industry standard 8-12%)
- Engagement time: 20%+ longer on recommended articles
- Retention: 30% more repeat visits
- Topic expansion: 20% of readers explore outside main interest

**Implementation time:** 8-12 weeks for full rollout  
**Who owns it:** Tech + Content + Analytics team
