
## Link Priority Rules

1. **Primary Link** (image wrap): Most relevant user guide section
2. **Secondary Link** (caption): Beta guide testing section
3. **Tertiary Link** (caption, if applicable): Related user guide section

**Example** (Mood Tracker image):
- **Primary**: `/user-guide/#mood-tracker-20` (image wrap)
- **Secondary**: `/beta-guide/#january-2026-powertools` (caption)
- **Tertiary**: `/user-guide/#wellness-hub` (caption)
