# Store Assets Guide

## Icons
- iOS App Store icon: 1024x1024 PNG (no transparency)
- Android adaptive icon: foreground 432x432 within 1080x1080 PNG

## Feature Graphic (Android)
- 1024x500 PNG or JPG, no transparency

## Screenshots
- Aim for 6–8 per platform; include primary flows
- iOS sizes: 6.7", 6.5", 5.5" (at minimum)
- Android: Phone (1080x1920), 7", 10"

## Tips
- Avoid placeholder lorem ipsum in public listings
- Ensure accessibility features are visible (good PR)
- Localize captions if you ship localized UI
