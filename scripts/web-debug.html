3mpwr App Web Diagnostic

Console Errors:

Steps:

  1. Open browser console (F12)
  2. Check for red errors
  3. Check Network tab for failed requests
  4. Common issues:
    • CORS errors with Firebase
    • Module not found errors
    • React render errors
    • Auth initialization failures

Quick Fixes:

  • White screen + no errors: Check if app is loading at all (view source)
  • Firebase errors: Check .env file has correct Firebase config
  • Module errors: Run npm install
  • Build errors: Run npx expo start --web --clear
