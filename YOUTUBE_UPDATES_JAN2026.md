## 🎬 Video Production Tips

### Best Practices
1. **Show Real Features** - Use actual app for demos, not stock footage
2. **Slow Pacing** - Allow time for viewers to follow along
3. **Add Captions** - Essential for accessibility (include in video description link)
4. **High Contrast** - Make sure UI is visible on phone screens
5. **Test Audio** - Clear audio is critical for screen reader users
6. **Include Links** - Put all resources in video description

### Accessibility Checklist
- [ ] Captions/subtitles (auto and manual review)
- [ ] Audio description for key visual demonstrations
- [ ] Links in description to featured resources
- [ ] Clear audio without background music (or very low)
- [ ] High contrast between text and background
- [ ] Screen reader tested (read aloud to verify clarity)

### Engagement Tips
- **Ask Questions**: "What advocacy tool do you wish you had?"
- **Share Stories**: "A viewer told me this changed their life because..."
- **Create Playlists**: "Getting Started" playlist with all beginner videos
- **Pin Comments**: Share helpful comments from viewers
- **Respond to Comments**: Show community you care
