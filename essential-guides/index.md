Each guide is:

## 📖 About These Guides

### How We Keep Guides Current

Each guide shows "Last updated: [date]" at the top and bottom. We refresh guides:
- **Monthly:** Core guides on benefits, WSIB, accommodation
- **As needed:** When laws/policies change (flagged with ⚠️ POLICY CHANGE notice)
- **Quarterly:** All other guides reviewed and refreshed

We track policy changes across:
- Federal (CPP-D, Canada Disability Benefit, ADA)
- Provincial (ODSP, AISH, PWD benefits, WCB/WSIB updates)
- Regulatory (AODA, provincial human rights codes)

### What Each Guide Includes

Every guide has:
- Key terms decoded
- Common mistakes to avoid
- Timeline (how long things take)
- Where to get help
- When things change (policy updates)

**We keep them current** — Every guide shows the last update date. If you find outdated info, [let us know]({{ '/contact' | relative_url }}).
