## 🌟 Mission & Values (NON-NEGOTIABLE)

The following are the **permanent, unchangeable mission** of 3mpwrApp™:

1. **Free & accessible** to all injured workers and disabled people (no paywalls)
2. **Privacy-first** (BYOC architecture, zero data collection, users own their data)
3. **Community-led** (decisions guided by injured workers, not corporations)
4. **Disability justice** (intersectional, anti-ableist, pro-labor)
5. **Open source** (AGPL-3.0, transparent development)

**These values CANNOT be changed, even by the founder.**  

Anyone who tries to commercialize, surveil, or exploit this project is violating its core mission and will be publicly called out.

## 🍴 Forking Policy

3mpwrApp™ is open source (AGPL-3.0). You're free to fork, but:

### **Friendly Forks (ENCOURAGED):**

**Examples:**
- **Regional adaptations:** "3mpwrApp Quebec" with French-first interface
- **Specialized versions:** "3mpwrApp for Construction Workers" with industry-specific resources
- **Accessibility variants:** "3mpwrApp for Deaf Community" with ASL video resources

**Requirements:**
- ✅ Use different name (not "3mpwrApp" or confusingly similar)
- ✅ Credit original project: "Forked from 3mpwrApp™ (3mpwrapp.ca)"
- ✅ Share improvements (AGPL-3.0 copyleft requirement)
- ✅ Maintain mission alignment (free, privacy-first, disability justice)
- ✅ Link to original project in documentation

**Benefits:**
- Original project benefits from your improvements (copyleft)
- You benefit from future original project updates
- Community benefits from diverse adaptations

---

### **Hostile Forks (DISCOURAGED):**

**Examples:**
- ❌ Forks that commercialize (charge fees, sell data, premium features)
- ❌ Forks that violate privacy (remove BYOC, add tracking, sell user data)
- ❌ Forks that claim to be "official" 3mpwrApp
- ❌ Forks that partner with insurance companies
- ❌ Forks that remove disability justice principles

**Consequences:**
- **We will publicly call out hostile forks** (website, social media, GitHub)
- **We will warn community** ("This fork violates our mission")
- **We will document violations** (how fork betrayed values)
- **We will not provide support** (no tech assistance, no partnership)

**Legal Protections:**
- Trademark (3mpwrApp™) prevents confusing names
- AGPL-3.0 requires source code sharing (can't hide exploitative code)
- Community can identify hostile forks via code review

## ⚖️ Dispute Resolution

**If disagreements arise between founder and community:**

1. **Direct conversation** (DM, email, or video call)
   - Founder and dissenter discuss issue privately first
   - Goal: Understand each other's perspective

2. **Public discussion** (GitHub issue or community forum)
   - If private conversation doesn't resolve, make it public
   - Community weighs in with feedback
   - Founder explains reasoning transparently

3. **Mediation** (neutral third party from community)
   - If public discussion doesn't resolve, request mediator
   - Mediator: Someone trusted by both parties (e.g., Emergency Council member)
   - Goal: Find compromise that serves mission

4. **Founder decides** (final authority)
   - After mediation, founder makes final call
   - Founder must explain decision publicly with reasoning
   - Decision can be revisited if new information emerges

5. **Dissenter can fork** (if decision is unacceptable)
   - Dissenter follows Friendly Fork policy
   - Both projects coexist, community chooses which to use
   - Copyleft ensures both projects benefit from each other's improvements

**Transparency:** Major disputes will be documented publicly (anonymized if needed for safety)

## 🔐 Security & Privacy Commitments

**Non-Negotiable Privacy Principles:**

1. **BYOC (Bring Your Own Cloud) Architecture**
   - Users' personal data stays in THEIR Google Drive/OneDrive
   - We never touch, store, or transmit personal data
   - Cannot be changed without violating core mission

2. **Zero Analytics Tracking**
   - No Google Analytics
   - No Facebook Pixel
   - No user behavior tracking
   - Cloudflare Web Analytics only (no personal data)

3. **Operational Data Only**
   - Firebase stores: Campaigns, events, community posts (public data)
   - Firebase NEVER stores: User profiles, evidence, medical records, tribunal docs

4. **Transparent Security**
   - All code is open source (security by transparency)
   - Security audits documented publicly
   - Vulnerabilities patched within 48 hours
   - Dependabot active (automated security monitoring)

**If BYOC or privacy principles are violated, community should fork immediately.**
