## 📱 Google Play Requirements

### Screenshot Specifications
- **Minimum:** 2 screenshots required
- **Recommended:** 4-8 screenshots for best presentation
- **Format:** JPEG or 24-bit PNG (no alpha)
- **Dimensions:** 
  - Minimum: 320px
  - Maximum: 3840px
  - **Recommended for phone:** 1080 x 2400 (9:19.5 ratio - modern Android)
- **File size:** Max 8MB per screenshot

## 🎨 Screenshot Best Practices

### Before You Start
1. ✅ **Clean device state**
   - Close other apps
   - Clear notifications
   - Full battery or hide status bar
   - Good Wi-Fi connection

2. ✅ **App preparation**
   - Sign in or use Guest mode
   - Navigate to each screen
   - Ensure data is loaded
   - Check for any error states

3. ✅ **Visual quality**
   - Use device with good screen resolution
   - Avoid over-exposure or dark screens
   - Ensure text is readable
   - No Lorem ipsum or placeholder text

### During Screenshot Capture

#### Option A: Android Device (Recommended)
1. **Physical device:** Press Volume Down + Power simultaneously
2. **Emulator:** Click camera icon in emulator toolbar
3. **ADB command:** `adb exec-out screencap -p > screenshot.png`

#### Option B: Screen Recording + Frame Extraction
1. Record screen while navigating
2. Extract best frames from video
3. Crop to remove status bar if needed

#### Option C: Expo Snack / iOS Simulator
1. iOS Simulator: `Cmd + S` to save screenshot
2. Android Emulator: Camera button in toolbar

### After Capture
1. ✅ **Review each screenshot**
   - Is text clear and readable?
   - Is the feature highlighted obvious?
   - Any sensitive data visible? (Remove if yes)
   - Correct aspect ratio?

2. ✅ **Edit if needed**
   - Crop to standard dimensions (1080 x 2400)
   - Remove status bar if distracting
   - Add subtle drop shadow for presentation (optional)
   - Ensure consistency across all screenshots

3. ✅ **Organize files**
   - Name clearly: `01-home-dashboard.png`, `02-wellness-hub.png`, etc.
   - Save in dedicated folder: `docs/store-listing/screenshots/`
   - Keep originals as backup

## 📐 Image Editing (Optional)

### Tools
- **Windows:** Paint, Paint 3D, Snipping Tool
- **Online:** Figma, Canva, Photopea
- **Android:** Built-in screenshot editor
- **Professional:** Adobe Photoshop, GIMP

### Recommended Edits
1. Crop to 1080 x 2400 (9:19.5 ratio)
2. Ensure consistent brightness/contrast
3. Remove sensitive user data (if any)
4. Optional: Add very subtle frame or shadow

### What NOT to do
- ❌ Don't add heavy filters
- ❌ Don't obscure key features
- ❌ Don't use fake/mock data
- ❌ Don't add excessive text overlays
- ❌ Don't misrepresent functionality
