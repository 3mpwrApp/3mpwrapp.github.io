## 🆘 Troubleshooting

### "I don't have time to post 2x per day"
→ **Solution:** Use automation (Option 3: Buffer bulk upload). 1 hr setup, then zero daily work.

### "These posts don't sound like me"
→ **Solution:** Month 1 calendar is a TEMPLATE. Edit tone/voice to match yours. Key: keep structure (hook → value → CTA).

### "I don't have a founder story for Post 2A"
→ **Solution:** Use Template 1 (Feature Spotlight) instead. Or talk about WHY you're building 3mpwrApp (doesn't have to be personal injury).

### "I don't have CanLII data yet"
→ **Solution:** Use placeholder discoveries from month1-complete-calendar.md OR skip CanLII posts, replace with extra feature spotlights.

### "No one is engaging with posts"
→ **Solution:** 
1. Are you engaging WITH others first? (reply before you post)
2. Using hashtags? (#DisabilityRights #WSIB minimum)
3. Posting in peak hours? (8-11 AM, 6-9 PM local)
4. Check viral hooks rotation (might be underperformers)
