## Content Batching Strategy

### Option 1: Weekly Batch (2 hours)
Every Sunday morning:
1. Write 7 posts (1 per day) using templates above
2. Save as drafts or schedule via platform tools
3. Daily task = just engage with replies (15 min)

### Option 2: Daily Fresh (30 min)
Every morning:
1. Check trending hashtags in [public/social-trends.json](public/social-trends.json)
2. Pick template that fits current community conversation
3. Customize + post
4. Engage in replies (15 min)

**Recommended:** Mix both—batch 4-5 planned posts (Mon-Fri), leave weekends flexible for real-time engagement

## Hook Rotation (Preventing Fatigue)

**From [scripts/viral-hooks-config.js](scripts/viral-hooks-config.js):**

### Emotion-Based Hook Categories:
1. **Urgency** - "🚨 PSA:", "⚠️ Deadline approaching"
2. **Curiosity** - "The secret nobody tells you", "What if I told you..."
3. **Validation** - "It's not just you", "You deserve..."
4. **Empowerment** - "Fight back", "Know your rights"
5. **FOMO** - "Most people don't know", "Finally available"
6. **Emotion** - "This broke my heart", "Here's why I'm angry"
7. **Numbers** - "22 templates", "3 minutes to..."

**Rotation Rule:** Don't use same emotion hook type 2 days in a row. Mix for variety.

**Example Weekly Mix:**
- Mon: Validation
- Tue: Curiosity
- Wed: Emotion (community spotlight)
- Thu: Numbers (feature stat)
- Fri: Empowerment (AMA)
- Weekend: Urgency or FOMO

## Platform-Specific Optimization

### Mastodon
- **Length:** Use full 500 chars (longer posts OK here)
- **Threads:** Multi-part tutorials work great
- **CW (Content Warnings):** Use for sensitive topics
- **Alt Text:** REQUIRED (community enforces)
- **Best Format:** Educational threads, deep dives

### Bluesky
- **Length:** 300 chars (shorter than Mastodon)
- **Threads:** Works well, use for storytelling
- **Quote Posts:** Add commentary to others' content
- **Best Format:** Quick tips, visual posts with commentary

### X/Twitter
- **Length:** 280 chars (punchiest hooks)
- **Threads:** Essential for longer content
- **Hashtags:** Max 2-3 per post (more looks spammy)
- **Best Format:** Breaking news, real-time commentary, quote tweets

### Facebook
- **Length:** Longer is fine (storytelling platform)
- **Visuals:** Carousels (multi-image) perform well
- **Questions:** Algorithm boosts comment engagement
- **Best Format:** Long-form stories, event promotion, community discussion

## A/B Testing Framework

**What to test:** Hook variations for same feature

**Example:**
- **Version A (Validation):** "It's not just you—the system is designed to exhaust you"
- **Version B (Empowerment):** "Fight back with tools built BY injured workers"
- **Version C (Curiosity):** "The one thing WSIB doesn't want you to know"

**Process:**
1. Post Version A on Monday
2. Post Version B on Thursday (same feature, different hook)
3. Track engagement for 7 days (see [ENGAGEMENT_TRACKING_WORKFLOW.md](ENGAGEMENT_TRACKING_WORKFLOW.md))
4. Compare engagement rates
5. Use winning hook type more frequently

**Test 1 hook variation per week** - more = confusion

## Measuring Content Performance

### Track These Metrics Per Template:
1. **Engagement Rate** (likes + shares + replies) / impressions
2. **Click-Through Rate** (link clicks / impressions)
3. **Save Rate** (bookmarks / impressions) - indicates value
4. **Time to First Reply** - faster = more engaging hook

### After 30 Days, Rank Templates:
- **Top 3 performers** → Use 2x more frequently
- **Middle performers** → Keep rotating
- **Bottom 3** → Retire or redesign
