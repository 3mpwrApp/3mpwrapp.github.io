## Quick Start

### First Time Using the App?

**📺 NEW: [Watch our Getting Started video tutorial →](https://www.youtube.com/watch?v=4i6xPpik_6M)**  
*Learn how to install, set up permissions, and understand privacy settings (5 minutes)*

**Step-by-Step:**

1. **Create Account** - Email, password, or continue as guest
2. **Choose Complexity Mode** - Simple (5 features), Standard (20), or Power User (150+)
3. **Set Up Profile** - Add your disability type, symptoms, and preferences (optional)
4. **Explore Features** - Start with Home tab Quick Actions

**Recommended First Steps:**
- Try the [AI Advocate Translator](#ai-advocate-translator) - paste confusing text, get plain language
- Save something to [Evidence Locker](#evidence-locker) - test encrypted storage
- Browse [Support Groups](#support-groups) - find your community
