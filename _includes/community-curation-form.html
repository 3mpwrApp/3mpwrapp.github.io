--- ## BACKEND IMPLEMENTATION ### API Endpoint: POST /api/community/submit-story **Request body:** ```json { "article_url": "https://...", "topic": "workers-rights", "reason": "This affects WSIB claimants...", "submitter_email": "optional@email.com" } ``` **Response:** ```json { "success": true, "message": "Story submitted for review", "id": "story_123" } ``` **Backend actions:** 1. Validate URL is publicly accessible 2. Store in "pending_stories" database table 3. Send to moderation queue 4. Flag with topic category 5. Log submitter email (if provided) 6. Send confirmation email ### API Endpoint: POST /api/community/vote **Request body:** ```json { "article_url": "https://...", "vote_type": "very-relevant|somewhat-relevant|not-relevant" } ``` **Backend actions:** 1. Record vote in analytics 2. Aggregate votes per article 3. Feed into curator scoring algorithm 4. Track voting patterns by topic ### API Endpoint: POST /api/community/request-topic **Request body:** ```json { "topics": ["housing", "transportation"], "details": "We need more coverage of..." } ``` **Backend actions:** 1. Store in "topic_requests" table 2. Aggregate by frequency 3. Report to editorial team monthly 4. Adjust curator weights based on patterns --- ## MODERATION WORKFLOW ### Daily Moderation Process 1. **Morning:** Editor checks "pending_stories" queue 2. **Review:** Assess each submission against criteria (3 min per story) 3. **Approve:** Add to curation feed with "Community Suggested" tag 4. **Decline:** Send decline message explaining why 5. **Track:** Log decision for patterns ### Criteria for Approval ✅ **APPROVE if:** - From credible news source (news org, government, academic, nonprofit) - Directly relevant to disability/injury/accessibility - Not already covered (check recent curations) - Respectful and factual - Complete article available (not paywalled) ❌ **DECLINE if:** - Promotional/sponsored content - Unproven treatments/pseudoscience - Paywall-only (users can't read) - Discriminatory language - Off-topic or tangential - Already covered recently ### Declining Respectfully Send brief, constructive response: > "Thank you for the suggestion! This article doesn't quite fit our focus on disability rights and practical navigation. We appreciate your help in keeping us informed though—keep them coming!" --- ## MONTHLY REPORTING **Community Curation Report includes:** 1. Stories submitted this month 2. Approval rate 3. Top topic requests 4. Vote patterns (which articles rated most relevant) 5. Engagement from suggested articles 6. Adjustments to curator.json based on feedback ---
